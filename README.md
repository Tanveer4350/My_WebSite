## 📌 About the Project
This is my personal portfolio website designed to showcase my skills, projects, and interests
as a 2nd year Computer Science student. The website focuses on clean design, smooth visuals,
and an interactive experience using Three.js.

The portfolio is fully responsive and aims to provide a simple yet engaging way to present
my work and technical background.

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript
- UI/UX Designing
- Three.js  
- GitHub Pages (Deployment)

---

## ✨ Features
- Interactive 3D visuals powered by Three.js
- Responsive design for different screen sizes
- Clean and minimal UI
- Deployed using GitHub Pages

- Structuring a portfolio website using HTML and CSS
- Improving UI/UX through animations and layout design
